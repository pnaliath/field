Recommended installation

  1. Download Field-Setup.exe.
  2. Close FL Studio before running the installer.
  3. Run the installer and complete the installation.
  4. Open FL Studio.
  5. Load Field on the Master track.

Manual installation using the ZIP

  1. Download Field-FL-Studio-Manual.zip and extract it.
  2. Close FL Studio.
  3. Copy the extracted Field 1 Beta folder into FL Studio's native Effects folder. The default Windows location is:
C:\Program Files\Image-Line\FL Studio <version>\Plugins\Fruity\Effects\
  1. The final folder should contain Field 1 Beta_x64.dll and Plugin.nfo.
  2. Open FL Studio.
  3. Load Field on the Master track.

If FL Studio is installed in a custom location, use that installation folder and then navigate to Plugins\Fruity\Effects.
